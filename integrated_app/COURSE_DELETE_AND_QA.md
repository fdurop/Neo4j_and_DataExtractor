# 课程彻底删除与通用知识问答（2026-11-03）

## 问答

- 所选课程没有相关资料时，真实调用模型回答，服务器添加“通用知识回答”说明，sources 为空，answer_mode 为 general。
- 已检索的资料不足以支持回答时，丢弃未获支持的课程结论，另调用一次通用知识问答；单次提问最多两次模型请求，仍受调用预算限制。
- 资料充分时保留课程依据和引用校验，answer_mode 为 course。
- 检索、模型、配置或引用校验故障仍明确报错，不伪装成“没有资料”。
- 通用回答不得编造课件内容、实验参数或来源；不能确认的课程细节应明确说明。

## 删除

- DELETE /api/courses/<course_id> 现在执行彻底删除，不再归档；只有教师可操作。成功返回 success/deleted，不再返回 archived。
- 页面保留一次不可撤销确认；请求期间禁用对应按钮，显示等待状态，成功刷新列表，失败提供重试。
- 删除课程目录记录、课程归属的原生节点/关系、课程根节点、GraphRevision 历史、当前本地图谱快照、该课程上传任务及源文件/处理产物，以及当前/上次记录索引中的课程向量。
- Neo4j 删除前检查异常归属及跨课程关系，删除事务中再次检查；按课程 ID 参数化执行，不按节点名称删除。
- 同课程的 HTTP 上传、重试、编辑和问答与删除互斥；存在活动任务或尚未结束的处理线程时拒绝删除。
- 多存储系统无法组成一个事务；删除开始后持久化 deleting 状态和任务目录清单。失败时保留目录记录供重试，课程暂停使用，不报告成功。重复清理不会重新创建数据。
- 递归清理前校验绝对路径，并拒绝外部链接/目录联接。共享预算账本及人工历史备份不作课程活动数据删除。
- 既有归档课程不自动清理。并发协调针对当前单实例本地服务，不是独立服务器之间的分布式锁。

## 后续验证与恢复补充

- 最终完整离线测试共 229 项通过。
